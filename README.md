# 🥤 いなむーレジェンズ (Inamu Legends)
**Pixel Art Online Battle & Strategy Game**

🎮 **今すぐ遊ぶ**: https://inamu-legends.onrender.com/

AIによって制作された、キメラ合成・デッキ編成・リアルタイムオンライン対戦が楽しめるWebゲームです。

---

## 🕹️ ゲームの特徴

- **キメラ合成・図鑑**: ユニットを合成して強化。特定の組み合わせでシークレットキメラ（全30種）に進化！ シークレット同士を合成すると、正体不明の最終形態「？？？」に。
- **デッキ編成**: 最大10枚のデッキで自分だけの最強チームを編成しよう。
- **オンライン対戦**: 世界中のプレイヤーとリアルタイム対戦。レート戦（ELO）にも対応。
- **ホーム画面**: 自分のレート・ランキング・オンラインの人・対戦待ちの人数・全体チャットが一目でわかります。
- **CPU対戦**: 10段階の難易度（易しい〜鬼、さらにバフ付きの修羅〜無限）のBotと対戦。オンラインで相手が見つからないときは自動でBot戦になります。
- **練習場**: かかし相手にユニットの火力（DPS）を試せるサンドボックス。CPUの強さ・マナ無限・HP無限・両方の陣地に置くなどを自由に設定できます。
- **スマホ対応**: タッチ操作・ピンチズームに対応。

## 🌐 公開方法（Render.com）

このリポジトリは Render.com で公開しています。GitHub に push すると、数分で自動的に新しい版が公開されます。

初めて設定するとき:
1. [Render.com](https://render.com/) に GitHub アカウントでログインします。
2. **「New +」** → **「Blueprint」** を選び、このリポジトリを連携します。
3. `render.yaml` が自動で読み込まれるので **「Apply」** を押します。

※ 無料プランのため、しばらく誰も遊ばないとサーバーが休止し、次に開いたときの起動に数十秒かかります。
※ 無料プランではサーバーが再起動すると `server/userdata.json`（レート・デッキなど）と `server/chat_history.json`（全体チャットの履歴）が消えることがあります。レートなどは各プレイヤーのブラウザにも保存されています。

## 💻 自分のパソコンで動かす（テスト用）

[Node.js](https://nodejs.org/) が必要です。

- **Windows**: `start.bat` をダブルクリックすると、サーバーが起動してブラウザが開きます。
- **コマンド**:
  ```bash
  npm install
  npm start
  ```
  起動後、ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

GitHub Codespaces でも起動できます（`.devcontainer` の設定で自動起動します）。
