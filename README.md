# 🥤 いなむーレジェンズ (Inamu Legends)
**Pixel Art Online Battle & Strategy Game**

AIによって制作された、キメラ合成・デッキ編成・リアルタイムオンライン対戦が楽しめるWebゲームです。

---

## 🎮 起動方法（ローカル環境）

### 方法1: Windowsで起動する
1. **`start.bat`** をダブルクリックして起動します。
2. 自動的にサーバーが立ち上がり、ブラウザが開きます。

### 方法2: コマンドで起動する
```bash
# 依存関係をインストール
npm install

# サーバー起動
npm start
```
起動後、ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

---

## 🌐 GitHubでサーバーを立てて公開する方法

### 【方法A: GitHub Codespacesで今すぐ起動する（一番簡単！）】
1. このリポジトリのGitHubページを開きます。
2. 緑色の **「Code」** ボタンを押し、**「Codespaces」** タブを選んで **「Create codespace on main」** をクリックします。
3. クラウド環境が自動で準備され、サーバーが起動します！
4. 画面右下に表示される「ブラウザーで開く」または「ポート 3000」の地球マークをクリックすると、公開URLが発行され友達と一緒に遊べます。

### 【方法B: Render.com で24時間無料公開する】
1. このプロジェクトを自分の **GitHub リポジトリ** にプッシュ（アップロード）します。
2. [Render.com](https://render.com/) にアクセスし、GitHubアカウントで無料登録・ログインします。
3. **「New +」** → **「Blueprint」** を選択します。
4. この GitHub リポジトリを選択して連携します。
5. リポジトリ内の `render.yaml` が自動的に読み込まれるので、**「Apply」** を押すだけで数分後に世界中に公開されたURLが発行されます！

## 🕹️ ゲームの特徴

- **キメラ合成・図鑑**: 様々な素材を組み合わせて新しいキメラを発見！
- **6枚デッキ編成**: 自分だけの最強チームを編成しよう。
- **レート対戦 (ELO)**: クラウドで対戦レートが自動保存される本格マッチメイキング。
- **マルチプレイ**: 同じWi-Fi内の友達や、クラウドサーバー経由で世界中のプレイヤーとリアルタイム対戦！
