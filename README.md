# 🥤 いなむーレジェンズ (Inamu Legends)
**Pixel Art Online Battle & Strategy Game**

🎮 **今すぐ遊ぶ**: https://inamu-legends.onrender.com/

AIによって制作された、キメラ合成・デッキ編成・リアルタイムオンライン対戦が楽しめるWebゲームです。

---

## 🕹️ ゲームの特徴

- **キメラ合成・図鑑**: ユニットを合成して強化。特定の組み合わせでシークレットキメラ（全30種）に進化！ シークレット同士を合成すると、正体不明の最終形態「？？？」に（同じシークレットどうしなら「極」）。合成した能力はすべて組み合わさり、同じ能力を重ねるとレベルアップ（最大Lv6）。
- **デッキ編成**: 最大10枚のデッキで自分だけの最強チームを編成しよう。
- **オンライン対戦**: 世界中のプレイヤーとリアルタイム対戦。レート戦（ELO）にも対応。
- **ホーム画面**: 自分のレート・ランキング・オンラインの人・対戦待ちの人数・全体チャットが一目でわかります。
- **CPU対戦**: 10段階の難易度（易しい〜鬼、さらにバフ付きの修羅〜無限）のBotと対戦。オンラインのマッチングは、待っている時間を表示し、相手が見つかるかキャンセルするまで待ちます（CPUとは自動で対戦しません）。
- **将棋・チェス**: 2人（正式ルール）・3人・4人（十字形の盤、王を取られたら脱落）の将棋とチェス。オンライン・CPU・同じ画面で交代で遊べます。
- **結果画面・サドンデス**: 試合が終わると勝ち負け・時間・ダメージなどを表示。3分を過ぎるとサドンデスで本体へのダメージが2倍（そのあと1分ごとに上がる）。
- **はじめてガイド**: はじめて開いたときに、遊び方を4ページで説明します（メニューからいつでも見られます）。
- **練習場**: かかし相手にユニットの火力（DPS）を試せるサンドボックス。CPUの強さ・マナ無限・HP無限・両方の陣地に置くなどを自由に設定できます。
- **スマホ対応**: タッチ操作・ピンチズームに対応。

## 🌐 公開方法（Render.com）

このリポジトリは Render.com で公開しています。GitHub に push すると、数分で自動的に新しい版が公開されます。

初めて設定するとき:
1. [Render.com](https://render.com/) に GitHub アカウントでログインします。
2. **「New +」** → **「Blueprint」** を選び、このリポジトリを連携します。
3. `render.yaml` が自動で読み込まれるので **「Apply」** を押します。

※ 無料プランのため、しばらく誰も遊ばないとサーバーが休止し、次に開いたときの起動に数十秒かかります。
※ 無料プランではサーバーが再起動すると `server/userdata.json`（レート・デッキなど）と `server/chat_history.json`（全体チャットの履歴）が消えることがあります。レートなどは各プレイヤーのブラウザにも保存されています。

### 🇸🇬 サーバーをシンガポールに移す（オンライン対戦のラグをへらす）

今のサーバーはアメリカ（オレゴン）にあり、日本からの往復に約0.1秒かかります（2026-11-21に測定）。日本から近いシンガポールに移すと、待ち時間が短くなる見込みです。Renderではサーバーの場所をあとから変えられないため、新しく作り直します。

1. [Render.com](https://render.com/) にログインし、**「New +」→「Web Service」** を選ぶ。
2. このリポジトリ（Inm-Legends）を選ぶ。
3. 次のように入力する。
   - **Name**: 好きな名前（例: `inamu-legends-sg`。これがURLになります）
   - **Region**: **Singapore (Southeast Asia)**
   - **Branch**: `main`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: **Free**
4. **「Advanced」→「Add Environment Variable」** で、`NODE_ENV` = `production`、`HOST_NAME` = `いなむーレジェンズ公式サーバー` を足す。
5. **「Create Web Service」** を押し、数分待つ。表示されたURL（例: `https://inamu-legends-sg.onrender.com`）で遊べるか確かめる。
6. 新しいほうで問題がなければ、古いサービス（オレゴン）を **「Settings」→「Suspend」** で止めるか削除する。

※ URLが変わるので、友だちには新しいURLを伝えてください。
※ 新しいサーバーでは、サーバーに保存されていたレートなどは引き継がれません（無料プランでは、もともと再起動で消えることがあります）。各プレイヤーのブラウザに保存されている分は残ります。

## 💻 自分のパソコンで動かす（テスト用）

[Node.js](https://nodejs.org/) が必要です。

- **Windows**: `start.bat` をダブルクリックすると、サーバーが起動してブラウザが開きます。
- **コマンド**:
  ```bash
  npm install
  npm start
  ```
  起動後、ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

GitHub Codespaces でも起動できます（`.devcontainer` の設定で自動起動します）。
